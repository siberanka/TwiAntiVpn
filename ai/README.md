# ai/

Working notes that keep the current state of TwiAntiVpn in one place for maintainers and
AI-assisted sessions. Read these files before changing the project and update them in the same
commit as the change they describe.

| File | Contents |
|---|---|
| [PROJECT_STATE.md](PROJECT_STATE.md) | Architecture, login-check pipeline, config compatibility rules, testing and release workflow, open items. |
| [TRUSTED_ISP_DATA.md](TRUSTED_ISP_DATA.md) | How the built-in trusted local ISP list is produced, verified and refreshed. |

These notes never contain credentials, tokens, private hostnames, personal data or machine-specific
paths. The repository is public.
